## v1.0 — Initial baseline

**Дата фиксации базовой версии:** 2026-08-28  
**Ветка:** `main`  
**Git Tag:** `v1.0`

### Описание базовой версии:
Стабильная полнофункциональная версия портала образовательных материалов практикума «СмыслоКод».

### Состав и функциональность версии v1.0:
1. **Интерфейс веб-портала (`index.html`, `styles.css`, `app.js`):**
   - Тёмная авторская тема оформления с терракотовым акцентом (`#d97757` на `#141413`).
   - Интерактивная боковая панель с древовидной структурой всех уроков и разделов.
   - Система табов для каждого урока: **«Материалы»**, **«Стенограмма»**, **«Презентация PDF»**.
   - Интерактивные аккордеоны для всех 10 этапов с элементами управления «Развернуть всё» / «Свернуть всё».
   - Кнопки быстрого копирования промптов и блоков кода в один клик с визуальным подтверждением.
   - Полнотекстовый поиск по базе материалов в режиме реального времени.

2. **Маршрутизация и публикация (`404.html`, `.nojekyll`):**
   - Внутренняя Single Page Application (SPA) маршрутизация на базе якорных ссылок (`#hash`), исключающая ошибки 404.
   - Fallback-перенаправление `404.html` для внешних прямых переходов на GitHub Pages.

3. **База данных материалов (`data/course_data.js` и `docs/`):**
   - Полная база из 15 уроков и стенограмм практикума без сторонних видеоплееров.
   - Исходные материалы в формате Markdown.

4. **Безопасность:**
   - Настроен `.gitignore` для исключения конфиденциальных данных, токенов и временных файлов.
