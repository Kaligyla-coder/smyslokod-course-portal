# ⚡ СмыслоКод: Портал Практикума по вайбкодингу

Полноценное интерактивное веб-приложение базы знаний и уроков практикума по вайбкодингу.

## 🌟 Возможности портала
- 📱 **Современный SPA-интерфейс** в тёмном стиле.
- 🔍 **Мгновенный поиск** по всем урокам, этапам, правилам и промптам (Ctrl + K).
- 📋 **Копирование промптов и кода в 1 клик** с визуальным подтверждением.
- ✅ **Интерактивный трекер прогресса** (сохранение в localStorage).
- 🎙 **Полные стенограммы эфиров** с переключением во вкладках.
- ⚡ **Полная автономность** — работает в любом браузере без внешних серверов.
