## Инструкция
 [Транскрипция эфира](/dashboard/praktikum-august-2026/transcription/2d3491c5-0c4c-4201-b3a6-be8b2152f4da)[Презентация эфира](https://storage.yandexcloud.net/smyslocode-uploads/presentations/1787854568668-fe0406da.pdf) 
### Что получится после инструкции

К концу дня твой проект живёт в интернете . Любой человек на планете может зайти по ссылке и увидеть, что ты собрал за три вечера. Код сохранён в GitHub (если что-то сломаешь - откатишь за три секунды), задеплоен на Vercel или Amvera (после каждого ``git push`` сервер сам пересобирает новую версию), ссылка отправлена в чат когорты.

 Время: 30-60 минут. Большую часть делает Claude, ты только говоришь, что делать.

 Дедлайн: 30 мая 23:59 МСК - мягкий, для дисциплины. Не успел - не страшно, главное факт сдачи.
 Зачёт - ссылка на работающий URL в чате когорты. Один шаг, не шесть. Не нужно подключать базу, дизайн, оплату - это бонусы. Без них зачёт уже есть. Главное правило сегодня: ничего не делай руками. Не пиши команды в терминале, не лезь в настройки. Всё - через Claude Code. Учишься управлять, а не исполнять. Если что-то не пошло - три выхода: 1) скопируй текст ошибки и вставь в Claude со словами «вот ошибка, почини»; 2) сделай скриншот непонятного места и скинь в Claude Code с вопросом «объясни проще»; 3) чат когорты или Маша. 
### Карта инструкции

### Этап 1. GitHub - облако для кода

 Зачем. GitHub - это «Яндекс.Диск» для кода, только умнее. Он помнит каждое изменение. Сломал что-то - откатил за три секунды и вернул рабочую версию. Без GitHub любая ошибка Claude может убить проект. И второе: чтобы задеплоить проект в интернет (Этап 2), Vercel и Amvera цепляются именно к GitHub-репозиторию.

Три слова, которые надо знать:
 - Репозиторий - папка проекта в облаке.
- Коммит - сохранение (как Ctrl+S, только для всего проекта сразу).
- Пуш - отправка сохранений в облако.
 
#### Шаг 1.1. Зарегистрируйся на GitHub (если ещё нет)

Зайди на [github.com](https://github.com) → кнопка Sign up → email + пароль + придумай логин. Логин и пароль запиши в менеджер паролей - пригодятся в Этапе 2.

#### Шаг 1.2. Подключи свой проект к GitHub

Открой Claude Code в папке своего проекта (тот, который собирали в Дне 2). Скопируй и вставь:
 Промпт для агента 📋 Копировать промпт Подключи этот проект к GitHub.

1. Если у меня ещё нет репозитория для этого проекта - создай ПРИВАТНЫЙ репозиторий на GitHub. Назови его по имени моего проекта.
2. Сделай первый коммит со всем кодом проекта.
3. Запуши в GitHub.
4. Покажи мне ссылку на репозиторий.

Если нужна авторизация GitHub - объясни пошагово, что мне нажать. Если что-то упало - прочитай ошибку и почини. [ещё 12 таких промптов →](/promty) 
 Как проверить, что получилось. Открой ссылку на репозиторий в браузере. Видишь свои файлы (``CLAUDE.md``, ``ai-clone/``, ``business/``, остальное)? Значит код в безопасности.

 Если получил ошибку - скопируй её полностью и вставь в Claude со словами «вот ошибка, почини». 90% случаев Claude сам разберётся (не настроен SSH-ключ, не залогинен в gh CLI, репозиторий с таким именем уже существует). Если не помогло - попробуй другой логин или удали свой репозиторий с тем же именем в GitHub.

#### Шаг 1.3. Откат как страховка (опциональная проба)

Чтобы убедиться, что страховка работает - сделай любую правку в коде и сразу откати. Промт:
 Промпт для агента 📋 Копировать промпт Изучи последний коммит - что мы туда залили? Откати последний коммит и верни рабочую версию. [ещё 12 таких промптов →](/promty) 
Claude прочитает diff, объяснит, что было в последнем коммите, и откатит за 3 секунды. Это убивает страх «сломаю и не починю». Любую поломку можно откатить одним промтом.

### Этап 2. Деплой - проект в интернете

 Зачем. GitHub хранит код, но это пока только файлы в облаке. Чтобы любой человек мог зайти по ссылке и увидеть твой проект - нужен сервер, который будет «показывать» этот код браузеру. Это и есть деплой.

Два пути на выбор. Vercel - стандарт мира, бесплатно для маленьких проектов, регистрация через GitHub. Amvera - российский путь, оплата рублёвой картой, серверы в Москве, встроенный прокси к Claude/OpenAI без VPN. Если ты в России без зарубежной карты - иди в Amvera. Если есть VPN и зарубежная карта - Vercel удобнее.

Выбери один путь и пройди только его. Второй можешь попробовать как бонус.

#### Путь А. Vercel (международный, бесплатный)

 Регистрация - 3 шага вручную (один раз): 
 - Зайди на [vercel.com/signup](https://vercel.com/signup) → нажми кнопку Sign Up with GitHub .
- Авторизуйся через GitHub → откроется пустой dashboard с кнопкой Add New Project .
- Эту кнопку не нажимай руками - деплой сделает Claude. Просто проверь, что аккаунт создан.
 Эти 3 шага один раз делаешь руками. Дальше - всё через Claude. 
 Деплой через Claude. Открой Claude Code в папке проекта, скопируй и вставь:
 Промпт для агента 📋 Копировать промпт Задеплой этот проект на Vercel.

1. Если нужен Vercel CLI - поставь его.
2. Подключи мой GitHub-репозиторий.
3. Настрой автодеплой: каждый git push в main = новый деплой.
4. После пуша пришли мне URL.
5. Если упало - прочитай vercel logs и почини (обычно env-переменная не залита). [ещё 12 таких промптов →](/promty) 
 Как проверить, что получилось. Claude пришлёт ссылку вида ``https://твой-проект.vercel.app``. Открой её в браузере. Видишь свой сайт? Готово. Теперь сделай любую мелкую правку в коде (например, поменяй заголовок), запушь - через 30 секунд Vercel сам пересоберёт сайт. Обнови вкладку и увидишь обновление. Это и есть автодеплой.

 Если получил ошибку. Самые частые:
 - «Build failed: missing environment variable» - какая-то переменная из ``.env`` не залита в Vercel. Скопируй текст ошибки в Claude со словами «вот ошибка деплоя, объясни какую переменную и куда добавить в Vercel UI».
- «Quota exceeded» - у тебя кончились бесплатные минуты сборки. Подожди час или подключи карту (для практикума бесплатного лимита хватит).
- «Project name conflict» - имя проекта занято. Промт: «переименуй проект на Vercel в ``моё-имя-001``, передеплой».
 
#### Путь Б. Amvera (российский, оплата картой РФ)

 Регистрация - 3 шага вручную (один раз): 
 - Зайди на [amvera.ru](https://amvera.ru) → нажми Регистрация → введи email и пароль (карту привязывать сразу не обязательно).
- Подтверди email → откроется dashboard. Найди раздел Приложения → кнопка Создать приложение .
- Свяжи свой GitHub-аккаунт через кнопку GitHub - это нужно, чтобы Amvera видела твой репозиторий.
 
 Деплой через Claude. Открой Claude Code в папке проекта:
 Промпт для агента 📋 Копировать промпт Задеплой этот проект на Amvera.

1. Подключи мой GitHub-репозиторий через Amvera CLI или API.
2. Настрой автодеплой при пуше в main.
3. Если нужны env-переменные - выпиши их список, я заведу через UI Amvera.
4. После деплоя пришли мне URL.
5. Если упало - прочитай логи Amvera и предложи, как починить. [ещё 12 таких промптов →](/promty) 
 Как проверить, что получилось. Claude пришлёт URL. Открой в браузере. Работает - готово. Запушь любую правку - Amvera сама пересоберёт.

 Если получил ошибку - скопируй её и вставь в Claude со словами «вот ошибка, почини». Amvera CLI отличается от Vercel, Claude знает оба.

 Развилка одной таблицей: 
 Vercel Amvera Регистрация Через GitHub Через email Цена Free + от $20/мес От 170 ₽/мес Оплата Иностранная карта Карта РФ 152-ФЗ (данные клиентов в РФ) Нет Да Прокси к Claude Нужен VPN Встроено Когда выбирать Стандарт, есть VPN РФ-данные, нет VPN 
### Этап 3. Ссылка в чат когорты - зачёт

Когда Vercel или Amvera прислали тебе URL и сайт открывается в браузере - кинь ссылку в чат когорты с короткой подписью «вот мой проект, задеплоил». Всё. Это и есть зачёт.

 Что делать с этим завтра. Сайт уже в интернете. Любой следующий ``git push`` = новая версия сайта без твоего участия. Это и есть Принцип №2 из Дня 1: работа сделана, когда делается без меня. Дальше - растишь функционал, подключаешь базу, добавляешь оплату, рекламируешь. На тренинге глубоко разбираем именно это.

### Бонусы для тех, кто захочет глубже

Эти этапы не для зачёта . Зачёт уже есть после Этапа 3. Бонусы - для тех, у кого осталось время и интерес копнуть дальше. Делай в любом порядке, любое количество, по одному за раз.

#### Бонус 1. Подключи PostgreSQL

PostgreSQL - стандартная база данных. Нужна, как только в проекте появляется что-то кроме статичных страниц: пользователи, формы, заказы, сообщения. Промт:
 Промпт для агента 📋 Копировать промпт Подключи к моему проекту PostgreSQL через одну кнопку моего хостинга (Vercel Postgres или Amvera Postgres).

1. Создай базу через CLI или объясни, как создать через UI.
2. Подключи к проекту через Prisma или Drizzle (выбери под мой стек).
3. Создай миграцию для первой таблицы - например, `users` с полями id, email, created_at.
4. Покажи, как делать запросы из кода. [ещё 12 таких промптов →](/promty) 
#### Бонус 2. Установи Aceternity UI и преобрази дизайн

[Aceternity UI](https://ui.aceternity.com) - библиотека из 200+ красивых компонентов. Промт:
 Промпт для агента 📋 Копировать промпт Установи Aceternity UI в мой проект.

1. Поставь библиотеку через npm/pnpm.
2. Замени hero-блок моего сайта на компонент Spotlight или Aurora из Aceternity.
3. Покажи результат в браузере. [ещё 12 таких промптов →](/promty) 
Через 5 минут болванка превращается в продукт.

#### Бонус 3. Подключи Яндекс.Метрику через Chrome Claude

Расширение Claude в Chrome видит вкладку браузера. Промт в Chrome Claude:
 Промпт для агента 📋 Копировать промпт Я открыл metrika.yandex.ru и зашёл в свой аккаунт. Создай мне новый счётчик для сайта [твой-URL]. После создания счётчика - возьми код счётчика и подскажи, куда его вставить в моём проекте (репозиторий: [ссылка на GitHub-репо]). [ещё 12 таких промптов →](/promty) 
Chrome Claude сам пройдёт мастер настройки в браузере. Тебе останется только подтвердить и закоммитить код в проект.

#### Бонус 4. Подключи приём оплаты в тестовом режиме (CloudPayments)

Только тестовый режим, без реальных денег. Чтобы потрогать, как работает приём оплаты в коде. Промт:
 Промпт для агента 📋 Копировать промпт Подключи к моему проекту CloudPayments в тестовом режиме.

1. Создай простую страницу «Купить» с одной кнопкой.
2. По нажатию открывается виджет CloudPayments.
3. Используй тестовые ключи (бесплатно, без реальных списаний).
4. Покажи, какие тестовые карты использовать для проверки. [ещё 12 таких промптов →](/promty) 
Боевые ключи и юр. оформление - на тренинге, отдельным блоком.

#### Бонус 5. Запусти `/security-review` на готовом проекте

Встроенная команда Claude Code, которая проходит проект и ищет уязвимости. В Claude Code набери:
 
/security-review 📋 Копировать Claude сам пройдёт по коду, найдёт где могут быть утечки (захардкоженные ключи, открытые endpoints, незакрытые SQL-инъекции) и предложит, что починить. Полезно перед тем, как показывать проект кому-то снаружи.

### Что дальше

Три вечера у нас закончились. Ты:
 - Поставил Claude Code, настроил голос, скриншот в буфер (День 1).
- Собрал ``ai-clone/``, ``business/``, ``mastery/``, скиллы, план (День 2).
- Выложил проект в интернет (сегодня).
 
Это 5% возможностей вайб-кодинга. Авторизация, личные кабинеты, админки, парсеры, боты, AI-агенты, SaaS-архитектура, мобильные приложения, продвижение - остальные 95%. Эти 95% - на тренинге : 10 эфиров за 30 дней + 30 дней с командой в чате. Если хочешь довести свой проект до уровня, который реально приносит деньги - приходи. Цена - 75 000 ₽. Дата ближайшего потока и бронь - в Личном кабинете.

А самое главное - у тебя теперь есть сообщество . Тот самый чат когорты, в который ты только что кинул ссылку на свой проект. Там же другие участники, такие же как ты, на той же стартовой линии. Кидайте друг другу проекты, смотрите чужие, перенимайте приёмы. Этот чат - твоя главная награда за три вечера. Не теряй его.
