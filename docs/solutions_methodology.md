# Готовые решения каталога
 
## Что такое «готовое решение»

Решение - это самодостаточный пакет: код, документация, промпты для AI-агента, иногда конфиги и шаблоны. Скачиваешь архив, отдаёшь его AI-агенту - и тот за минуту разворачивает всё внутри твоего проекта.

Каждое решение в каталоге - отдельная единица, которой можно пользоваться независимо от остальных. Внутри тренинга «СмыслоКод» это способ забрать готовый кусок системы СмыслоКода и адаптировать его под свою задачу, не изобретая заново.
 
## Почему через свою платформу, а не GitHub

Это закрытый каталог. Чтобы скачать решение, нужно быть участником тренинга с активным доступом. Если ты вернул деньги - доступ отзывается.

Каждая твоя копия персонально подписана. В архиве лежит файл LICENSE.txt, в котором указаны твоё имя, email и Tracking ID - идентификатор именно твоей копии. Если этот файл утечёт в открытый доступ, мы по Tracking ID находим источник.

На GitHub это сделать невозможно - там нет точечного контроля доступа и нет персональных копий.
 
## Как разворачивать через AI-агента
 - Скачай архив. Кнопка на странице решения. Файл называется ``<slug>-v<версия>.tar.gz``.
- Скопируй промпт. На странице решения есть готовый промпт для AI-агента. Промпт говорит агенту: «Распакуй архив рядом, прочитай LICENSE.txt и README, скажи, что готов».
- Дай AI задачу. Когда агент подтвердил, что прочитал содержимое - можешь работать с пакетом: попросить адаптировать под свой проект, развернуть в текущей кодовой базе или объяснить структуру.
 
Наш канон - VS Code + Claude Code. Если Claude дорого, fallback - расширение ChatGPT для VS Code. Cursor, Windsurf, Replit, Bolt и Lovable не рекомендуем.
 
## Что такое Tracking ID

Это короткий идентификатор твоей копии. Он зашит в LICENSE.txt каждого скачанного архива и привязан к твоему аккаунту через email. Один пользователь + один пакет = один Tracking ID, не зависит от версии.

Tracking ID - не секрет. Это юр-инструмент: если копия с твоим Tracking ID окажется в открытом доступе, мы по логу скачиваний найдём источник утечки.
 
## Что нельзя делать
 - Передавать архив другим людям - даже родственникам или коллегам, которые не покупали тренинг.
- Выкладывать содержимое в публичные репозитории, в облачные диски с общим доступом, в чаты и каналы.
- Продавать или монетизировать сам пакет (включая «модифицированную версию»).
 
При обнаружении утечки доступ ко всем продуктам СмыслоКода отзывается без возврата денег. Подробные условия - в LICENSE.txt внутри архива и в оферте тренинга, которую ты подписал при оплате.

Использовать пакет в своих проектах (включая коммерческие) - можно и нужно, ради этого его и забирали.
